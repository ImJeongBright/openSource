# Phase 9: 통합 테스트 및 데모 시나리오 준비 상세 (AI 중심 - Developer B)

## 1. 개요
공모전 심사위원들에게 프로젝트의 가치를 직관적으로 전달하기 위해 가장 인상 깊은 AI 활용 시나리오를 구성하고 시연하는 단계입니다. 특히 RAG(Retrieval-Augmented Generation) 시스템의 효용성과 pgvector 기반 자체 구축 검색 시스템의 빠른 응답 속도를 증명합니다.

## 2. 세부 테스트 및 데모 기획

### 2.1. AI 자율 검색 시나리오 작성 (데모 스크립트)

#### 복합 추론 질문 시연
- 심사위원 데모 시 다음과 같이 단순한 키워드 검색으로는 찾기 힘든 복합적이고 문맥이 필요한 질문을 Claude(또는 LLM 에이전트)에게 던지는 시나리오를 짭니다.
  - *예시: "우리 회사 작년 보안 가이드라인(V1)과 올해 가이드라인(V2)을 비교해서, 암호 정책에서 어떤 항목들이 강화되었는지 표로 정리해 줘."*
- **자율 도구 호출 증명**: Claude가 질문을 받은 뒤 시스템의 프롬프트나 지시 없이 스스로 MCP의 `search_documents` 도구를 호출하여 관련 정책 문구들을 수집하고, 더 자세한 문맥이 필요하면 `get_chunk` 도구를 추가로 호출하는 **AI 자율적 사고 및 행동 과정(Agentic Behavior)** 을 터미널 실시간 로그와 함께 화면에 띄워 줍니다.

#### Traceability(추적성) 확인 증명
- Claude가 반환한 최종 답변 내에 "이 정보는 보안 가이드라인 V2의 34페이지 '비밀번호 정책' 섹션에서 발췌했습니다"와 같이 정확하게 출처를 밝히는 모습을 보여주어 할루시네이션(환각) 방지 및 신뢰성 기능을 어필합니다.

### 2.2. 속도 및 정확도 체감 증명

#### 대용량 문서 스케일 테스트
- 수백 혹은 수천 장 분량의 샘플 PDF(예: 대규모 사내 매뉴얼, 방대한 규정집 등)를 시스템에 미리 파이프라인 처리하여 적재해 둡니다.
- 방대한 데이터 속에서도 사용자의 자연어 질문을 벡터화하여 답을 찾아내는 전체 과정이 수 초 이내에 매끄럽게 이루어지는 것을 현장에서 증명합니다.
- 기술 어필 포인트: 백엔드에서 `pgvector`의 HNSW 인덱싱이 수백만 건의 벡터를 얼마나 효율적으로 서치하는지 속도적 우수성을 설명 자료에 포함합니다.
